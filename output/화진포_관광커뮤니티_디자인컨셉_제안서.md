# 화진포 시간의 호수
## 기억·생태·공존의 커뮤니티 플랫폼 디자인 컨셉 제안서

**부제**: 湖에서 만나는 역사와 자연, 그리고 우리의 내일
**제안 대상**: 강원도 고성군 화진포 관광지 커뮤니티 공간 조성 사업
**제안 일자**: 2026년 5월

---

## 1. 프로젝트 개요

화진포는 한반도 동해안 최대 석호이자, 이승만·김일성·이기붕 별장이 공존하는 냉전 기억의 현장이며, 수십만 마리 철새가 해마다 귀환하는 생태계의 보고다. 이 세 가지 층위—역사, 자연, 생명—는 서로 분리된 관광 자원이 아니라, '시간'이라는 하나의 축 위에서 중첩되는 유기적 서사다.

본 프로젝트는 화진포의 분산된 관광 자원을 하나의 통합 브랜드와 공간 서사로 연결하고, 방문객이 단순 관람을 넘어 역사를 성찰하고 생태를 체험하며 지역 공동체와 교류하는 **살아있는 문화 플랫폼**을 구축하는 것을 목표로 한다.

| 항목 | 내용 |
|------|------|
| 위치 | 강원도 고성군 거진읍 화진포 일원 |
| 사업 성격 | 관광지 커뮤니티 공간 브랜딩 및 공간 조성 |
| 사업 기간 | 1단계 12개월 조성 + 연간 운영 |
| 예산 규모 | 1단계 7.5억~12.5억 원 (2단계 미디어아트 포함 시 상향) |
| 주요 대상 | 역사 탐방형, 생태·자연 추구형, 가족·교육형, MZ 감성 여행형, 접경·평화 관심형 |

## 2. 공간명 및 브랜드 슬로건

**공간명**: 화진포 시간의 호수 (Hwajinpo — Lake of Time)

**메인 슬로건**: 정지된 시간, 살아있는 물빛

**서브 슬로건**:
- 호수는 기억한다 (역사 테마)
- 철새는 돌아온다 (생태·귀환 테마)
- 경계에서 만나다 (평화·공존 테마)

**로고 컨셉**: 석호 수면 위 소나무 반영을 미니멀 라인으로 표현한 심볼. 한자 '湖(호)'의 필획을 현대적으로 재해석하여 물결과 문자가 중첩되는 형태. 국문 워드마크는 윤명조 계열 세리프체, 영문은 Cormorant Garamond 적용.

## 3. 핵심 콘셉트

### 3-1. 세 개의 시간축

| 층위 | 키워드 | 공간 구현 |
|------|--------|-----------|
| 지질·생태의 시간 | 수만 년의 형성 | 석호 산책로, 생태 해설 데크 |
| 역사·권력의 시간 | 냉전과 분단 | 별장 AR 해설, 기억의 길 |
| 귀환·공존의 시간 | 철새·사람·미래 | 미디어아트, 커뮤니티 마당 |

### 3-2. 핵심 콘셉트 키워드

- **호(湖) — 머무름과 순환**: 석호는 바다도 강도 아닌 경계의 공간. 공존의 감각을 회복하는 은유적 무대.
- **기억(記憶) — 권력과 장소의 중층성**: 남과 북의 지도자 별장이 같은 호수를 바라보는 역사적 아이러니를 직시하고 성찰하는 장.
- **귀환(歸還) — 철새처럼, 사람처럼**: 해마다 돌아오는 철새의 서사를 통해 '돌아옴'이라는 보편적 감정—통일·귀향·회복—을 환기한다.

## 5. 공간 구성

### 5-1. 전체 동선

**권장 관람 동선 (3~4시간 / 야간 포함 시 5시간)**

```
Zone A (역사기억·별장)
  → Zone B (자연체험·석호·해변)
  → Zone C (커뮤니티 허브·박물관)
  → Zone D (야간 미디어아트)
```

전동 셔틀 카트 운행 (Zone A~D 순환, 20분 배차)
무장애 단축 동선: Zone C → A 핵심 구간 → Zone D (1.5시간)

### 5-2. Zone A — 역사기억 공간 (별장 구역)

**테마**: 냉전의 기억, 권력과 장소의 중층성

| 요소 | 내용 |
|------|------|
| AR 해설 태블릿 | 별장별 역사 인물·시대 배경 증강현실 해설 (한·영·일 3개국어) |
| 기억의 길 안내판 | 연대기 순 스토리텔링 패널 (냉전 철회 컬러 디자인) |
| 원형 보존 원칙 | 문화재청 협의 기반, 외부 구조물 변경 최소화 |
| 야외 전시 | 분단 시기 생활사 아카이브 사진전 (계절별 교체) |

> **법적 선결 조건**: 등록문화재 현상변경 허가 취득 후 시공 착수

### 5-3. Zone B — 자연체험 공간 (석호·해변)

**테마**: 수만 년의 생태, 철새의 귀환

| 요소 | 내용 |
|------|------|
| 석호 일주 산책로 | 4km 전 구간, 목재 데크 3개소, 생태 해설 QR 안내판 |
| 탐조 거점 | 철새 도래 시즌(10~3월) 전용 관찰 데크, 망원경 렌털 |
| 가변형 이벤트 무대 | 소규모 버스킹·생태 교육 프로그램 운영 |
| 시그니처 포토스팟 | 석호 데크 전망대 (수평 반영 구도 최적 위치) |

### 5-4. Zone C — 커뮤니티 허브 (박물관·카페·상업)

**테마**: 지역 공동체와의 만남, 서사의 결산

| 요소 | 내용 |
|------|------|
| 박물관 로비 라운지화 | 방문객 휴식·교류 공간, 화진포 아카이브 열람 코너 |
| 어촌 마켓 | 고성 지역 수산물·특산물 정례 마켓 (매월 2회) |
| 팝업숍 | 지역 작가·청년 창업자 입점, 3개월 단위 교체 |
| 예술가 벽화 | 박물관 외벽, 공모 선정 지역 작가 제작 |
| 오리엔테이션 존 | 전체 관람 안내, 지도 배부, 스탬프 투어 시작점 |

### 5-5. Zone D — 미디어아트 공간 (야간 연출)

**테마**: 귀환·경계·공존 — 밤의 언어로 말하다

| 요소 | 내용 |
|------|------|
| 태양광 LED 경관 조명 | 석호 수변 전체 경관 조명, 탄소중립 운영 |
| 프로젝션 맵핑 | 박물관 외벽: '철새의 귀환' 애니메이션 시즌 상영 |
| 수상 조명 부이 | 석호 수면 부유형 LED, 물 반영 연출 |
| 야간 내러티브 | '경계를 넘는 빛' — 분단·귀환·통일 이미지 시퀀스 |

## 6. 프로그램 운영 계획

### 6-1. 연간 정기 프로그램

| 시기 | 프로그램 | 대상 |
|------|----------|------|
| 봄 (3~5월) | 철새 귀환 축제, 생태 사진 공모전 | 전 연령 |
| 여름 (6~8월) | 야간 미디어아트 시즌 공연, 어촌 마켓 확대 운영 | 가족·MZ |
| 가을 (9~11월) | 평화·접경 포럼, 역사 탐방 교육 프로그램 | 교육형·성인 |
| 겨울 (12~2월) | 철새 탐조 투어, 동해 일출 명상 프로그램 | 자연 추구형 |

### 6-2. 상시 프로그램

- **스탬프 투어**: Zone A~D 4개 구역 완주 시 기념품 증정
- **화진포 아카이브 워크숍**: 지역 어르신 구술 채록·기록 (분기 1회)
- **청년 아티스트 레지던시**: 지역 청년 예술가 3개월 입주 지원, 결과물 Zone C 전시

### 6-3. 거버넌스 및 운영 주체

| 주체 | 역할 |
|------|------|
| 고성군청 | 사업 주관, 예산 집행, 문화재청 협의 |
| 화진포 박물관 | 역사 콘텐츠 자문, Zone A·C 공동 운영 |
| 지역 어촌계 | Zone C 어촌 마켓 운영, 수익 직접 귀속 |
| 지역 예술가 협회 | 벽화·레지던시·팝업숍 콘텐츠 공급 |
| 전문 운영사 (위탁) | 미디어아트·AR 시스템 유지보수, SNS 마케팅 |

**수익 배분**: 입장 수익의 20% 지역 공동체 기금 적립, 어촌 마켓·팝업숍 매출 100% 입점자 귀속

## 마무리

화진포 시간의 호수는 하나의 관광지 리뉴얼 사업이 아니다. 분단과 생태와 공동체라는 세 개의 서사가 석호를 매개로 만나는 **접경 문화 플랫폼**이다. 정지된 듯 보이는 이 호수는 사실 수만 년을 흘러왔고, 앞으로도 계속 흐를 것이다. 이 제안서가 그 흐름 위에 사람과 기억과 미래를 함께 담는 그릇이 되기를 기대한다.
