## 1. 공간 개요 및 존 분석

### 1.1 시설 기본 정보

| 항목 | 사양 |
|-----|------|
| **시설명** | 화진포 관광커뮤니티센터 |
| **위치** | 강원도 고성군 화진포 (동해 해변) |

### 2.2 1F 섹션 상세 계획

#### 2.2.1 관광사진 천정 갤러리

**개념**: 입장 직후 자연스럽게 시선을 상향으로 유도하여 "발견의 순간" 연출

**위치 및 규격**:
| 항목 | 사양 |
|-----|------|
| **위치** | 정문 좌측, 자연채광 활용 (유리창 쪽) |
| **레일 구성** | STAS Cliprail Pro 또는 Systematic Art Sky Rail |
| **레일 개수** | 3-4개 (평행 배치, 1.2m 간격) |
| **레일 길이** | 약 8-10m (공간 폭 전체) |
| **마운트 높이** | 바닥에서 2.2-2.5m (안전 마진) |
| **재질** | 양극산화 알루미늄 (실버 또는 매트 블랙) |
| **최대 하중** | 65kg/m (충분한 안전마진) |

**사진 배치**:
| 항목 | 사양 |
|-----|------|
| **사진 규격** | A2 (420×594mm) 또는 16:9 프레임 (600×337mm) |
| **프레임** | 매트 블랙 또는 자연 목재 (5-10mm 두께) |
| **레일당 사진 수** | 4-6개 (회전 공간 확보) |
| **총 전시 사진** | 15-20개 (계절별 교체) |
| **마운트 시스템** | STAS 전용 클립 (무손상, 조정 용이) |
| **간격** | 사진 간 50-100mm (시각적 리듬) |

**조명 계획**:
| 항목 | 사양 |
|-----|------|
| **유형** | LED 트랙 라이트 (35-50W, 2700-3000K) |
| **배치** | 각 레일 상단 또는 천정 매입 (각도 조절) |
| **각도** | 사진에 수직 입사 (반사 최소화) |
| **밝기** | 300-500 lux (전시용 표준) |
| **색온도** | 4000-5000K (사진 색감 충실) |

**테마 로테이션** (월 1회 교체):

| 시즌 | 테마 | 주요 이미지 | 감정톤 |
|------|------|-----------|--------|
| **봄 (3-5월)** | "새로운 시작" | 벚꽃, 산책로, 신록 | 신선함, 활기 |
| **여름 (6-8월)** | "물의 즐거움" | 해변, 물놀이, 가족 | 즐거움, 활동성 |
| **가을 (9-11월)** | "조용한 명상" | 단풍, 황금빛, 일몰 | 평온함, 감성 |
| **겨울 (12-2월)** | "고요한 아름다움" | 해일, 적막, 바다 | 신비로움, 고요 |

**특별 테마** (분기별 또는 특정 행사):
- "화진포의 비경" (랜드마크 특집)
- "고성의 사계절" (연속 시리즈)
- "관광객의 순간" (사용자 생성 콘텐츠 - UGC)
- "역사와 문화" (문화유산, 유적지)

**설치 및 유지보수**:
- **초기 설치**: 3-4일 (레일 마운트, 사진 배치)
- **월 1회 교체**: 2-3시간 (기존 사진 제거, 신규 배치)
- **정기 청소**: 월 1회 (레일, 프레임, 렌즈 먼지 제거)
- **안전 점검**: 분기별 (클립 강도, 마운트 상태)

**예상 비용**:
- 레일 시스템: ￥1,500,000-2,000,000
- 조명(LED 트랙): ￥400,000-600,000
- 프레임(20개) + 마운트: ￥100,000-200,000
- **소계**: ￥2,000,000-2,800,000

```
     [정문]
```
