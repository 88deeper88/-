# 디자인컨셉: 화진포 관광커뮤니티센터

## 1. 시각적 아이덴티티

### 1.1 디자인 철학

**콘셉트**: "동해 자연 속 신뢰와 편안함"

화진포 관광커뮤니티센터의 시각적 아이덴티티는 고성의 자연 자산(동해 바다, 백사장, 하늘)을 직관적으로 표현하면서도, 정보 신뢰성과 가족 친화성을 동시에 전달합니다.

**3가지 축**:
1. **자연성(Natural)**: 고성의 해변, 하늘, 바다를 연상시키는 컬러와 형태
2. **신뢰성(Trustworthy)**: 관광정보를 제공하는 기관으로서의 전문성과 신뢰감
3. **친근성(Approachable)**: 모든 연령대, 특히 가족 관광객과의 감정적 연결

### 1.2 시각적 계층

**1F (정보·전시 층)**:
- 명확성과 신뢰감 강조
- 수평 라인, 정보 구조의 명확성
- 거리감 있으면서도 전문적인 분위기

**2F (휴식·체험 층)**:
- 편안함과 활동성의 균형
- 유연한 곡선, 따뜻한 온기
- 다세대가 함께하는 포용적 분위기

## 3. 타이포그래피

### 3.1 폰트 선택 전략

**원칙**:
1. **명확성**: 정보 전달의 정확성이 최우선 (1F)
2. **친근성**: 모든 세대의 접근성 (가독성, 크기)
3. **다국어 지원**: 한글/영문/중문/일문 동시 지원
4. **신뢰성**: 공공기관의 전문성 반영

| 용도 | 한글 | 영문 | 용도 및 특성 |

## 4. 이미지 스타일 및 톤앤매너

### 4.1 관광사진 큐레이션 스타일 (1F 천정 갤러리)

#### 4.1.1 주제 분류

**계절별 시리즈** (월 1회 교체):
- **봄(3-5월)**: 벚꽃, 산책로, 새로운 시작 이미지
- **여름(6-8월)**: 해변, 물 활동, 가족 재미
- **가을(9-11월)**: 단풍, 황금빛, 조용한 명상
- **겨울(12-2월)**: 해일, 적막, 고요한 아름다움

**공간별 시리즈**:
- 화진포의 비경 (랜드마크)
- 해수욕장 (활동)
- 유명 카페/레스토랑 (미식)
- 등대, 유적지 (역사·문화)
- 일출/일몰 (감정적 순간)

#### 4.1.2 사진 프레임 규칙

| 특성 | 기준 |
|-----|------|
| **비율** | 16:9 또는 4:3 (천정 레일 마운트에 최적화) |
| **노출** | 밝고 맑은 톤 (어두운 음영 회피) |
| **구도** | 수평선 명확, 삼분할 원칙 준수 |
| **채도** | 자연스러운 포화도 (과도한 보정 금지) |
| **초점** | 선명도 우선, 소프트 포커스 효과 최소화 |
| **색감** | 자연 색감 유지, CMYK 최적화 (인쇄 품질) |

#### 4.1.3 사진 감정톤

| 감정 | 시각적 요소 |
|-----|-----------|
| **신뢰감** | 맑은 날씨, 밝은 구도, 선명한 초점 |
| **경험감** | 사람이 포함된 활동 장면 (아이, 가족) |
| **발견감** | 새로운 각도, 미지의 장소, 호기심 유도 |
| **편안감** | 부드러운 빛(golden hour), 차분한 색상 |

## 5. 가구·설치 시스템 및 재질 선택

### 5.1 1F 설치 시스템 (천정 갤러리)

#### 5.1.1 천정 레일 시스템

**선택 제품**: STAS Cliprail Pro 또는 Systematic Art Sky Rail

**사양**:
| 항목 | 사양 |
|-----|------|
| **재질** | 양극산화 알루미늄 (내식성, 경량) |
| **색상** | 매트 실버 또는 블랙 (천정과 통합) |
| **최대 하중** | 65kg/미터 (안전마진 확보) |
| **마운트** | 천정 구조재에 볼트 고정 (목재/콘크리트 모두 가능) |
| **간격** | 1.2m ~ 1.5m 중심간격 (설치 균형) |

**천정 구성**:
- **길이**: 공간 폭 전체 (약 8-10m 상정)
- **개수**: 평행선 3-4개 (시각적 리듬)
- **높이**: 바닥에서 2.2m 이상 (관광객 통행 안전)

#### 5.1.2 사진 마운트 시스템

**마운팅 방식**:
- **클립 시스템**: STAS 전용 클립 (조정 용이, 손상 없음)
- **사진 크기**: A2 (420x594mm) 또는 16:9 프레임
- **프레임**: 매트 블랙 또는 자연 목재 (색상 통일)
- **간격**: 레일당 4-6개 사진 (시각적 리듬, 회전 공간 확보)

**교체 주기**:
- 매월 1회 계절별 시리즈 교체
- 연 특별 테마 (지자체 행사, 기념일) 운영

| **좌/우 벽면** | 노출 콘크리트 또는 갤러리화이트 | #FAF7F2 (따뜻한 화이트) | 갤러리 분위기 |

**천정 갤러리 조명**:

- **색온도**: 4000-5000K (중립적, 사진 색감 충실)
- **설치 각도**: 갤러리 사진에 수직 입사 (반사 최소화)

**일반 조명**:
- **천정 매입 LED 패널**: 3000K (따뜻함)
- **밝기**: 300-500 lux (정보 습득 최적 수준)

**강조 조명**:
- **키오스크 배경**: 간접 LED (파란 톤, 신뢰감 강조)
- **정보부스**: LED 스탠드 라이트 (1000-1500K, 친근함)

### 5.3 기둥 벤치 설계 (사각기둥 원형 벤치)

#### 5.3.1 구조 및 형태

**개념**:
- 건축 기둥(보통 500x500mm 또는 600x600mm 콘크리트)을 감싸는 원형 목재 벤치
- 구조적 필요성(기둥 보호)을 디자인 기회로 전환
- 가족 단위가 마주보며 앉을 수 있는 배치

**규격**:
| 항목 | 사양 |
|-----|------|
| **외경** | 기둥 크기 + 600mm (예: 600mm 기둥 → 1200mm 외경) |
| **높이** | 450-480mm (앉았을 때 편한 높이) |
| **깊이** | 350-400mm (등을 기댈 수 있는 충분한 너비) |
| **모양** | 완전 원형 (또는 기둥에 맞춘 다각형) |

#### 5.3.2 재질 및 마감

**목재 선택**:
- **종류**: 편백나무 또는 낙엽송
- **내구성**: 해변 습도 견딤(함수율 12% 이하)
- **마감**: 자연유(식물성 오일) 또는 우레탄 도료 (정기 유지)

**색상**:
- **1순위**: #8B6F47 (온화한 목재톤) - 자연스러운 편백
- **2순위**: #A8B5A5 (밝은 톤) - 밝고 현대적 분위기

**안전 마감**:
- 모든 모서리 및 표면 라운드 처리 (R10mm 이상)
- 스플린터(가시) 제거 (샌딩 마무리)
- 미끄럼 방지: 저마찰 자연유 마감 (안전성 우선)

#### 5.3.3 설치 및 유지보수

**기초**:
- 기둥 바닥에 고정 브래킷 (스테인리스 스틸)
- 기둥과의 간격 10-20mm (습기 순환)

**정기 유지**:
- 분기별(3개월) 오일 재도장
- 연 1회 깊은 세정 및 보호제 도포
- 손상 부위 즉시 수리 (곰팡이, 균열 방지)

### 5.4 놀이시설 재질 및 안전기준

#### 5.4.1 편백나무 큐브 풀 (Wooden Ball Pool)

**안전기준**: CPSC (Consumer Product Safety Commission) 및 ASTM F963 준수

**큐브 스펙**:
| 항목 | 사양 |
|-----|------|
| **볼 크기** | 70mm 이상 (질식 위험 방지) |
| **볼 재질** | 편백나무(천연 목재) |
| **마감** | 자연유(독성 없는 식물성 오일) |
| **볼 개수** | 1,000-1,500개 (풀의 깊이 60-80cm 기준) |
| **색상** | 자연 목재톤 또는 파스텔 톤 염색 |

**안전 특성**:
- 통풍성: 편백 다공성으로 악취 방지
- 항균성: 편백 휘발유의 천연 항균 작용
- 부드러움: 콘크리트 볼보다 충격 완화
- 생분해성: 환경친화적

**크기별 권장사항**:
- **3-5세**: 풀 깊이 40-50cm
- **6-12세**: 풀 깊이 60-80cm
- **혼합 이용**: 깊이 60-70cm 권장

#### 5.4.2 풍선 설치 (Balloon Installation)

**제품 사양**:
| 항목 | 사양 |
|-----|------|
| **풍선 재질** | 천연 라텍스 또는 합성 고무 |
| **크기** | 22-28cm (큰 충격 흡수) |
| **색상** | 파스텔 톤 (부드러움) |
| **수명** | 3-6개월 (정기 교체) |
| **헬륨** | 불필요 (무게로 안정성 확보) |

**설치 방식**:
- **배치**: 풍선을 큐브 풀 표면에 배치(떠있음)
- **고정**: 가벼운 어댑터로 로프 고정 (떨어지지 않도록)
- **밀도**: 풀 표면의 50-60% 커버 (이동성 유지)

**안전 관리**:
- 주 1회 손상 풍선 제거
- 월 1회 전체 교체 (박테리아 관리)
- 수명 만료 풍선은 즉시 제거

#### 5.4.3 풀 프레임 구조

**구조**:
| 항목 | 사양 |
|-----|------|
| **외경** | 2000 x 2000mm (또는 1500 x 2500mm) |
| **높이** | 600-700mm (출입 용이) |
| **재질** | 고급 목재 프레임 또는 FRP (강화플라스틱) |
| **컬러** | #C9836B (테라코타) 또는 자연 목재톤 |
| **출입구** | 2개 이상 (안전 및 시선 확보) |

**내부 안전**:
- 바닥 쿠션(EVA 폼, 두께 50mm)
- 측벽 패딩(충격 완화)
- 모서리 모두 라운드 처리

#### 5.4.4 정기 소독 및 관리 시스템

**일일 관리**:
- AM 9:00: 표면 검사 및 손상 풍선 제거
- PM 6:00: 휴무 전 차단(입장 금지 표지)

**주 2회 세척** (권장: 화요일, 목요일):
1. 풍선 전체 제거
2. 큐브 진공청소 또는 드라이 세척
3. 큐브 자외선 살균(30분)
4. 풍선 세정(알칼리성 세제) 또는 신규 교체
5. 모든 큐브 재배치

**월 1회 정밀 관리**:
- 큐브 샘플 검사 (10-15개)
- 박테리아 배양 검사
- 손상 큐브 제거 및 신규 교체
- 관리 기록 작성

**분기별 대청소**:

- 쿠션/패딩 세척
- 구조 안전성 확인
